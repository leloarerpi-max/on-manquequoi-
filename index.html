    Mes repas

    Un repas par ligne (collez-les ou importez un fichier .txt / .csv). Format complet : Nom du plat #étiquette x2 : 400g pâtes, 2 tomates, 1 oignon

    • x2 ou | 2 après le nom : plat prévu sur 2 jours (ou bouton « 2 j » dans la liste).
    • #poisson, #végé… : étiquettes pour les règles de la semaine.
    • Ingrédients automatiques : pour les plats classiques (lasagnes, quiche, saumon, chili…), la liste de courses se remplit toute seule. Pour imposer les vôtres, mettez-les après :, séparés par des virgules (ou via le crayon).
    • favori (revient plus souvent) · à éviter cette semaine · modifier étiquettes et ingrédients.

              Synchronisation entre appareils

              Utilisez le même code famille sur le téléphone et l'ordinateur : repas, recettes, règles et courses restent identiques partout, presque en direct. Les données restent aussi sur chaque appareil : l'application fonctionne sans connexion et se met à jour dès que le réseau revient.

              📱 Vous utilisez l'application depuis l'écran d'accueil : elle a sa propre mémoire, séparée de Safari. Activez-y la synchronisation une seule fois : sur l'ordinateur, cliquez sur « Copier les infos de connexion », envoyez-vous le texte, puis collez-le dans la case 1 ci-dessous et cliquez sur « Activer ».

              2. Code famille (le même sur tous vos appareils ; il sert de mot de passe)
              Code famille :

              Ouvrez le lien d'invitation sur votre téléphone (ou envoyez-le à votre femme) : tout est configuré d'un coup. Si le lien ne marche pas : cliquez sur « Copier les infos de connexion », collez-les dans la case 1 de l'autre appareil (section Synchronisation) puis cliquez sur « Activer ». Attention : le lien et le code donnent accès à vos menus, ne les partagez qu'avec votre famille.

              Comment créer la base en ligne gratuite (une seule fois, environ 10 minutes)
              1. Allez sur console.firebase.google.com et connectez-vous avec un compte Google.
              2. Cliquez sur Ajouter un projet, donnez-lui un nom (par exemple « on-mange-quoi »), désactivez Google Analytics, puis créez le projet.
              3. Dans le menu de gauche : Créer (ou « Build ») → Firestore Database → Créer une base de données. Choisissez un emplacement en Europe, puis le mode production.
              4. Ouvrez l'onglet Règles, remplacez tout le contenu par les règles ci-dessous, puis cliquez sur Publier.
              5. Cliquez sur la roue dentée ⚙ → Paramètres du projet → section Vos applications → icône </> (Web). Donnez un nom, enregistrez, puis copiez le bloc firebaseConfig affiché.
              6. Collez ce bloc dans la case 1 ci-dessus, cliquez sur Générer un code puis Activer la synchronisation.
              7. Cliquez sur Copier le lien d'invitation et ouvrez-le sur votre téléphone : la synchronisation s'active toute seule.

              Les écrans de Firebase peuvent légèrement changer de nom. L'offre gratuite est largement suffisante pour une famille.
